## 踩坑记录（重要，后续写测试必看）
**本环境 FastAPI 用惰性 `_IncludedRouter`，`app.routes` 不展开子路由** ——
直接遍历 `app.routes` 只能看到 8 条（默认路由 + health + SPA），会误判"端点不存在"。
要做路由级检查，必须**递归展开 `_IncludedRouter`，或改用源码静态扫描**（我最终用的是后者）。
可用 `inspect.iscoroutinefunction(fn)` + `inspect.getsource(fn)` 正则扫描 `app/api/*` 模块。

## 第三轮：按 v2 报告实施修复（产出 FIXES_2026-09-27.md）

修了 21 项（P0×2、P1×10、P2×9）。关键改动与验证：

- **P0-2**：21 个含同步阻塞的 async 端点 → 复扫后 6 个且全为误报。

  **注意**：`engine_start` 等**不能**简单改成同步 `def` —— `task.start()` 内部调
  `asyncio.create_task()`，在线程池里没有运行中的事件循环会抛 RuntimeError。
- **P1-3**：`stops.py` ATR 无效（None/0/NaN）时 `new_stop=None` 跳过更新；
  `chandelier` 保留 1R 兜底（实测不受影响）。
- **P1-4**：`stop()` 必须**先撤保护性委托再 cancel 任务** —— 顺序反了的话
  `finally` 里的 await 会立刻重抛 CancelledError，撤单做不成。
- **P1-5**：缓存改「按路径加锁 + 写临时文件 + `Path.replace()` 原子替换」；
  实测 8 写线程 + 4×40 读线程 0 异常 0 短读。
- **P1-8**：Sortino 改全样本下行偏差，实测 0.6905 == 标准口径。
- **P2-1**：加 `_MIGRATE_INDEXES`（`CREATE INDEX IF NOT EXISTS`）——
  **`create_all` 不会给已存在的表补索引**，老库必须显式建。
- **P2-4**：`BrokerSettingsIn.host` 限定回环地址（堵 SSRF）。
- **P2-9**：删 `optimizer.PERIODS_PER_YEAR` / `annualize()` 死代码。
